# Tekton (tekton)

Tekton is a cloud-native CI/CD framework that runs as Kubernetes CRDs. The Tekton Pipelines API exposes Tasks, Pipelines, PipelineRuns, TaskRuns, and Triggers for building portable CI/CD workflows.
