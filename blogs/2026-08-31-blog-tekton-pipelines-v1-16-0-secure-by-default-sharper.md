We’re excited to announce the release of Tekton Pipelines v1.16.0 “Manx WALL-E” ! 🎉 Secure by default, sharper traces 🎉 Action Required: set-security-context Enabled by Default The headline change in this release: the set-security-context feature flag now defaults to true ( #9589 , #10680 ). Tekton-injected TaskRun containers and Affinity Assistants now get a restricted-compatible SecurityContext out of the box.
